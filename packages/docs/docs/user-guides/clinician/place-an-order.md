# Place an order and follow it up

Use this guide to order a lab test, an imaging study, or a referral to physiotherapy, nutrition, social work or counselling. Afiax sends each order straight to the right department's queue, where its staff pick it up.

For medicines, see [Prescribe a medicine](./prescribe-a-medicine.md).

**Who this is for:** clinicians.

**How long it takes:** under a minute per order.

## Where each order goes

| Order type | Goes to |
|---|---|
| Laboratory | Laboratory queue |
| Radiology | Radiology queue |
| Physiotherapy | Physiotherapy queue |
| Nutrition | Nutrition queue |
| Social work | Social work queue |
| Counselling | Counselling queue |
| Medication | Pharmacy queue (see [Prescribe a medicine](./prescribe-a-medicine.md)) |

## Before you start

You need a visit open for the patient, with status **arrived**, **triaged** or **in-progress**. See [Start a visit](./start-a-visit.md).

## Place an order

1. Open the patient's visit.
2. In the **Clinical orders** panel, click the **Place order** tab.
3. In **Order type**, choose the type, for example **Laboratory**.
4. In **Priority**, choose how quickly it's needed:
   - **Routine:** the normal order of work. This is the default.
   - **Urgent:** before routine orders.
   - **STAT (immediately):** an emergency. Also phone the department, following your facility's procedure.
5. Click the order box. It's labelled with the order type, for example **Laboratory (KNHTS)**. Type at least 2 letters of the test or service, for example `haemo`, and choose the right match from the list.
6. If the department needs to know something, type it in **Clinical note**, for example *query malaria, febrile 3 days*.
7. Click **Place order**.

{/* SCREENSHOT: Place order tab with a laboratory order filled in */}

**What you should see:** a green message such as **Laboratory order sent to Laboratory**. The form empties, ready for the next order.

To place several orders, repeat the steps for each one.

## Follow up an order

1. In the **Clinical orders** panel, click the **Order history** tab.
2. You'll see every order in this visit, newest first, with when it was **Ordered**, its **Type**, the **Order** itself, its **Priority**, and where it is in the **Department**.

The badge in the **Department** column tells you how far the order has got:

| Badge colour | It means |
|---|---|
| Grey | Waiting in the department's queue |
| Blue | The department has accepted it and is working on it |
| Green | Done, for example the test has been completed |
| Red | Cancelled or rejected |

## If something goes wrong

### "No KNHTS match"

Try a shorter search word, or another name for the test. Afiax only offers tests and services from the national terminology service (KNHTS), so local names may not be found.

### Place order is greyed out

You haven't chosen a test or service from the list yet. Typing in the box isn't enough: you must click one of the matches.

### The Place order tab is greyed out

The visit isn't active. See [Start a visit](./start-a-visit.md#if-something-goes-wrong).
