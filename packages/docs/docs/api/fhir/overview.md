# Overview

Afiax is based on the [FHIR API](https://www.hl7.org/fhir/R4/).

Afiax is "FHIR Native," using version 4.0.1 (aka R4), meaning the service stores data in the actual FHIR format, documented [here](/docs/api/fhir/resources). 

Afiax also implements [custom resource types](/docs/api/fhir/medplum) to handle user management, authentication, and authorization. 

The base URL for hosted Afiax is https://fhir.afiax.africa/fhir/R4
