# User Guides

These guides show facility staff how to do their everyday work in the Afiax Clinical Suite, one task per page. They are grouped by role, so you only need to read the part for your job.

Every guide describes the system as it works today. If a task isn't listed here, the screen for it hasn't been released yet.

## Before you start

- You need an Afiax account. Your facility administrator creates it and sends you an email invitation.
- Use a recent version of Chrome, Edge or Firefox.
- Start with [Sign in and keep your account secure](./front-desk/sign-in.md), whatever your role.

## How the guides are laid out

Every guide follows the same pattern, so once you've read one you know where to look in the others:

1. **Who it's for** and **how long it takes**
2. **Before you start:** what you need to have ready
3. **Numbered steps,** with the exact names of the buttons and boxes in **bold**
4. **What you should see,** so you know each step worked
5. **If something goes wrong:** the common problems and what to do
